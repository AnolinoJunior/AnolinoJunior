## 👩‍💻 About me

I'm a **DevOps Engineer at Bosch**, working on **TaxCalendar** — a global tax-compliance platform serving eight regions. Day to day that means Azure infrastructure, Terraform/Bicep, Azure DevOps & GitHub Actions pipelines, containers, and identity (Keycloak, Entra ID, OAuth2/OIDC, SCIM).

I took the long road into tech: six years in the Brazilian Navy, a degree in Cinema & Audiovisual, then a self-taught jump into cloud and automation. It taught me to ship under pressure, tell a clear story, and never do the same thing by hand twice.

- 🔭 **Currently:** building a Kubernetes home-server platform on my Raspberry Pi 5 homelab (`fuhro-network`), Zero Trust included
- 🎓 **Studying:** postgraduate in Software Architecture & AI Solutions (postgrad in Business Intelligence done)
- 📜 **Certified:** AWS Cloud Practitioner · EF SET English C2
- ✍️ **Writing:** technical posts in Portuguese on [LinkedIn](https://www.linkedin.com/in/giullialazaro) about DevOps, CI/CD and career transitions
- 🌍 **Open to:** DevOps / Platform / Cloud roles in Europe
