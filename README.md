## 👨‍💻 Sobre mim

Sou Anolino Junior, desenvolvedor com foco em **backend com C# e .NET**. Construo APIs e aplicações com **ASP.NET Core, Entity Framework Core e bancos de dados relacionais**, aplicando meus estudos em projetos práticos.

Gosto de entender como cada parte de uma aplicação funciona: da requisição HTTP à persistência dos dados, passando por validações, autenticação e tratamento de erros.

- 🛒 **Projeto atual:** VShop, um e-commerce em desenvolvimento com foco em uma loja virtual completa e funcional.
- 🧪 **Projeto em destaque:** BigBangAPI, uma API REST inspirada no universo de The Big Bang Theory.
- 📚 **Aprofundando conhecimentos em:** autenticação, autorização, integração entre aplicações e qualidade de APIs.
- 🎯 **Objetivo:** desenvolver sistemas úteis, confiáveis e fáceis de manter.
- 📫 **Contato:** [anolinojunioralves@gmail.com](mailto:anolinojunioralves@gmail.com)
- 💼 **LinkedIn:** [Anolino Alves](https://www.linkedin.com/in/anolino-alves-3b1b95158/)
